### Sobre mí

Me gusta construir productos digitales de punta a punta: desde interfaces limpias y fáciles de usar, hasta APIs, integraciones, bases de datos y despliegues en la nube.

Actualmente estoy fortaleciendo mi perfil en arquitectura fullstack, buenas prácticas de backend, automatización y servicios sobre AWS.

- Frontend con React, Next.js, Tailwind CSS y TypeScript.
- Backend con Node.js, NestJS, Express, Python y APIs REST.
- Bases de datos SQL y NoSQL como PostgreSQL, MySQL y MongoDB.
- Interés en cloud, serverless, CI/CD y arquitectura de productos reales.
- Enfoque en código claro, mantenible y orientado a negocio.
